# Gold/Silver AI

An Iran-first intelligent analysis system for gold, silver, and related investable
instruments — built to eventually help understand valuation, market conditions, and
portfolio decisions, with deterministic financial calculations at its core and AI
used only for interpretation and explanation, never as the source of numbers.

**Status:** Phase 0 — Foundation & Governance. No application functionality exists
yet. This phase establishes how the project will be built, documented, and reviewed
before any product code is written. See `docs/10-project-state/CURRENT_STATE.md`.

architecture, market, portfolio, data, AI, engineering, decisions, operations,
project state). Each folder has one job and one source of truth — see the table in
`CLAUDE.md` § 2 for exactly which file answers which question.

## Ground rules (short version)

- `main` is stable, owner-approved code only. All work happens on branches.
- Financial numbers are always computed by code, never generated by an AI model.
- Nothing about Iran's market is assumed from foreign-market behavior without
  Iran-specific validation.
- No fabricated data, ever. Unknowns are marked `STATUS: TBD`, not guessed.

Full rules: `docs/00-governance/PROJECT_RULES.md`.
